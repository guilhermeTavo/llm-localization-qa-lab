# Project Summary — LLM Localization QA Lab

## One-line Summary

A portfolio project that evaluates whether LLM-generated Portuguese content is accurate, natural and localized for Brazilian users.

## Why This Project Matters

Many LLMs can translate text into Portuguese, but not all outputs sound natural for Brazilian users.

This project focuses on practical Localization QA: checking meaning, tone, terminology, cultural fit and user impact.

## What Was Built

- Localization evaluation plan
- PT-BR localization rubric
- Severity guide
- 20 structured localization test cases
- Evaluation results template
- Defect log template
- Initial localization QA report

## Interview Pitch

I built a Localization QA lab to evaluate how well LLMs handle Brazilian Portuguese. The project includes 20 structured test cases, a localization rubric, severity criteria and QA templates for documenting defects. It focuses on whether model responses preserve meaning, sound natural to Brazilian users, use the right tone and handle product/support terminology correctly.
