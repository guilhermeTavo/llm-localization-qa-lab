Purpose

Localization is more than translation.

This project evaluates whether an LLM can preserve meaning while adapting tone, terminology, UX microcopy and support language for Brazilian users.

The review looks for issues that a fluent user would notice immediately: Portuguese-from-Portugal wording, false friends, literal translations, awkward SaaS terms, wrong date formats and support replies that sound unnatural.

Coverage

Meaning preservation

Checks whether translated content keeps the original intent without adding or removing critical details.

Natural PT-BR

Reviews whether the answer sounds like Brazilian Portuguese instead of literal translation.

Support tone

Evaluates empathy, clarity and usefulness in customer-facing replies.

Terminology

Flags SaaS, billing, login and account terms that feel unnatural or regionally wrong.

Cultural fit

Checks Brazilian date/time conventions, register, politeness and product language expectations.

Severity judgment

Classifies issues by user impact, from minor polish to release-blocking localization defects.

Workflow

PlanDefine the PT-BR localization dimensions and readiness threshold.
PromptCreate translation, support, UI, billing and technical-content scenarios.
ReviewScore each model response for meaning, naturalness, tone, terminology and cultural fit.
LogDocument localization defects with expected behavior, actual behavior, severity and recommendation.
DecideProduce a readiness verdict for Brazilian Portuguese release.
